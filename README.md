## Featured projects

### [SpendWise](https://github.com/thedevamina/SpendWise)
A full-stack mobile expense tracker built with React Native (Expo) + Node.js/Express + MongoDB.

- **Problem it addresses:** personal expense tracking and category-wise spending visibility in one app
- **What it includes:** JWT auth, persistent sessions, CRUD operations for expenses, protected routes, and spending analytics
- **Technologies:** TypeScript, React Native, Expo Router, Node.js, Express, MongoDB, Mongoose
